# ❌⭕ Tic Tac Toe

A fun and interactive Tic Tac Toe web game where two players compete in the classic X and O game. Enjoy a simple interface and challenge your friends!

## ✨ Features

- Two-player gameplay
- Interactive game board
- Automatic winner detection
- Draw detection
- Restart and play again option
- Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vibinsonraj05/Tic-Tac-Toe.git
```

### 2. Navigate to the project folder

```bash
cd Tic-Tac-Toe
```

### 3. Run the application

Open the HTML file in your web browser.

## 🎮 How to Play

1. Player 1 uses X.
2. Player 2 uses O.
3. Take turns selecting empty cells.
4. The first player to align three symbols horizontally, vertically, or diagonally wins.
5. If all cells are filled without a winner, the game ends in a draw.
